## Репозитории

### [Digital](https://github.com/nutpiks/Digital) — Python

Система аналитики Big Data для учреждений культуры. Веб-дашборд анализирует 
деятельность 5 организаций на основе квартальных Excel-отчётов: 20 листов 
превращаются в 130 показателей, считаются групповые статистики, проводится 
кластеризация (k-means), данные отдаются через 11 JSON-роутов FastAPI 
и визуализируются в тёмном дашборде на React.

**Стек:** Python, pandas, numpy, pyarrow, FastAPI, React 19, Vite, Docker.

**Роль:** аналитик и координатор проекта — постановка задач, декомпозиция, 
работа с данными, подготовка выводов и рекомендаций.

### [tatarby](https://github.com/nutpiks/tatarby) — JavaScript

Интеллектуальная платформа для изучения татарского языка русскоязычными 
пользователями. Включает распознавание текста с изображений (Tesseract OCR), 
перевод, морфологический разбор, тестирование уровня, адаптацию текстов, 
проверку сочинений через LLM и систему геймификации (XP, стрики, достижения).

**Стек:** React, Vite, JavaScript, FastAPI, PostgreSQL 16, Redis 7, JWT, Docker Compose.

**Роль:** фронтенд-разработка — вёрстка интерфейса, реализация пользовательских 
сценариев, интеграция с API, работа с состоянием и компонентами.

### [ds-hackathon](https://github.com/nutpiks/ds-hackathon) — Python

Spovatar — ИИ-тренер для Telegram. Бот анализирует тренировки пользователя, 
даёт персональные советы, помогает ставить цели и мотивирует. Интеграция 
с GigaChat API, умный разбор запросов, клавиатура с быстрыми действиями.

**Стек:** Python, python-telegram-bot, GigaChat-2-Max.

**Роль:** аналитик — подготовка данных, интерпретация результатов, 
проработка логики взаимодействия с ИИ.
